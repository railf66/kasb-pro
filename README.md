# Kasb Pro

Бесплатные уроки по рабочим профессиям: схемы, тесты, калькуляторы. Русский и узбекский.

Сайт: https://kasbpro.uz/ (старый адрес https://railf66.github.io/kasb-pro/ перекидывает сюда). Домен куплен в Eskiz, файл CNAME в корне не удалять.

Прогресс уроков хранится в браузере ученика (ключи вида `vn_*`, `hp_*`), язык общий для всех приложений (`ep_lang`).

- `index.html` — главная страница с профессиями
- `elektrik/` — приложение для электриков, уроки разложены по разрядам 2–6 (ЕТКС), экзамен и значок за каждый разряд, свидетельство. Исходники: папка проекта elektrik-app (`src/lessons.js`, `src/lessons2.js`, `src/app.js`), `python3 build.py` → `deploy-index.html`, копировать в `elektrik/index.html`.
- `certificate.js` — общее неофициальное свидетельство Kasb Pro (canvas → PNG): `KasbCert.open({prefix, lang, prof, grade, topics, sources, url, start})`. Имя хранится в `<prefix>_certname`. В Telegram вместо «Скачать» кнопка «Получить в чат»: картинка уходит в Make 8848306 (вебхук, проверка подписи initData), и @kasbpro_uz_bot присылает её фото в чат (ссылки data: в Telegram не скачиваются). Для профессий без разрядов (медсестра) есть необязательные `did`, `unit`, `shareText`, `note`.
- Разряды в остальных приложениях (сантехник, медсестра, оптик, сварщик, холод, автоэлектрик, видеонаблюдение, слаботочник, повар, кондитер, модельер, кафельщик): общий слой в папке проекта kasb-grades (`grades.js` — экзамен по 2 случайных вопроса с урока, порог 80 %, медаль, свидетельство; `apply.py` — собирает приложение и копирует в репозиторий). В каждом приложении `src/grades-cfg.js` (порядок уроков по разрядам, официальные источники) и `src/lessons-new.js` (новые уроки). Прогресс `<prefix>_done` сохраняется, сданные разряды `<prefix>_grades`. У медсестры не разряды, а 3 уровня (по профстандарту «Младший медицинский персонал»).
- `elektrik/igra/` — игра «Собери щиток» (RU/UZ, 2 минуты, 3 жизни): подбор автоматов, УЗО, кабеля и подключение проводов. Один файл `index.html`, копия в папке проекта elektrik-game. Кнопка «Поделиться» ведёт в бот `t.me/kasbpro_uz_bot?start=igra`. Ссылка на игру есть на главном экране Электрик Pro.
- `santehnik/` — приложение для сантехников (исходники: папка проекта santehnik-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`)
- `medsestra/` — приложение для медсестёр и медбратьев (исходники: папка проекта medsestra-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`). Только уход, первая помощь и санитария, без лекарств и доз.
- `optik/` — приложение для монтажников оптики (исходники: папка проекта optik-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`).
- `svarshik/` — приложение для сварщиков (исходники: папка проекта svarshik-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`).
- `holod/` — приложение для мастеров по кондиционерам и холодильникам «Холод Pro» (исходники: папка проекта holod-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`).
- `avtoelektrik/` — приложение для автоэлектриков и диагностов «Автоэлектрик Pro» (исходники: папка проекта avtoelektrik-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`).
- `videonablyudenie/` — приложение для установщиков видеонаблюдения (исходники: папка проекта videonablyudenie-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`).
- `povar/` — приложение для поваров (исходники: папка проекта povar-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"` и SEO-тегами).
- `slabotochnik/` — приложение для слаботочников «Слаботочник Pro»: СКС, домофоны, охранная и пожарная сигнализация, СКУД (исходники: папка проекта slabotochnik-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`, `tg.js` и SEO-тегами).
- `konditer/` — приложение для кондитеров «Кондитер Pro» (исходники: папка проекта konditer-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`, `tg.js` и SEO-тегами).
- `modeler/` — приложение для портних и модельеров «Модельер Pro»: мерки, ткани, швы, чертёж и пошив юбки, примерка, перевод вытачки, юбка-солнце, дизайн, своё ателье (исходники: папка проекта modeler-app, `python3 build.py`, затем копия `site-index.html` с `window.KASB_HUB="../"`, `tg.js` и SEO-тегами). Прогресс `mo_*`.
- `kafel/` — приложение для кафельщиков «Кафельщик Pro»: виды плитки, основание, раскладка, клей, укладка на пол и стены, резка, затирка, гидроизоляция, крупный формат, углы, смета; калькуляторы плитки, клея и затирки (исходники: папка проекта kafel-app, `python3 build.py`, затем скопировать site-index.html в kafel/index.html с SEO-шапкой)
- `mebel/` — приложение для мебельщиков «Мебельщик Pro» по разрядам 2–5 (по образцу ЕТКС): материалы, чертёж, раскрой, кромка, присадка, сборка корпуса, петли, ящики, монтаж кухни, шкаф-купе, замер, смета. После всех уроков разряда — экзамен (по 2 случайных вопроса с урока, порог 80 %) и медаль; сданные разряды дают неофициальное свидетельство Kasb Pro через `certificate.js`. Калькуляторы: раскрой ЛДСП с картой листов и кромка, фурнитура, двери купе, цена. Исходники: папка проекта mebel-app, `python3 build.py`, затем скопировать site-index.html в mebel/index.html с SEO-шапкой (KASB_HUB, tg.js, feedback.js, certificate.js). Прогресс `mb_*`.
- `prorab/` — «Прораб Pro»: акт приёмки выполненных работ и акт освидетельствования скрытых работ по СНиП (электрика, отделка, монтаж, сантехника, кровля, бетон, другое). Голосовой ввод (Web Speech API, иначе микрофон клавиатуры), фото в приложение к акту, PDF (pdfmake с Roboto, лежит в `prorab/lib/`, грузится только по кнопке) и Word (.doc). Один файл `index.html`, акты хранятся в браузере (`pr_acts`, `pr_profile`). Из Telegram кнопка «Открыть в браузере» переносит акт через `#d=` (без фото). Свой бот [@prorab_pro_uz_bot](https://t.me/prorab_pro_uz_bot) (сценарий Make «Prorab Pro Bot»), плашка tg.js ведёт туда через `window.KASB_BOT`; на главной Kasb Pro карточки нет — это рабочий инструмент, а не уроки. Третий документ — «Рапорт технадзора» о замечаниях (по образцу реального рапорта: шапка «Директору … от технического надзора», типовые пункты по виду работ, заключение, подпись).

## Telegram

- Общий бот: [@kasbpro_uz_bot](https://t.me/kasbpro_uz_bot) (сценарий Make «Kasb Pro Bot»). Ссылка `t.me/kasbpro_uz_bot?start=<папка>` сразу предлагает нужное приложение, `start=` записывается в таблицу как «Откуда пришёл».
- `tg.js` — плашка «Удобнее в Telegram» внизу приложения, если оно открыто в обычном браузере. При копировании новой сборки в папку профессии добавляйте рядом с `window.KASB_HUB` строку `<script src="../tg.js" defer></script>`.
